操作说明书 · User Guide

1 · 开启摄像头

  • 点右侧设置里的 开启摄像头 · Camera（或首屏的「立即开启摄像头」），允许浏览器权限。
  • 摄像头预览在屏幕正上方居中，和你的物理摄像头位置一致；手势骨架会画在预览画面上。
  • 状态显示 Camera Live 即成功；手势 AI 显示 Ready · 就绪 后才有手势控制。

2 · 手势控制

  • 张开手掌 OPEN：星星被推开，星云扩散。
  • 捏合 PINCH：产生引力，把粒子吸向掌心。
  • 握拳 FIST：聚拢收缩，形成一个致密核心。
  • 移动手掌：掌心就是引力点，星流会跟着你走。
  • 光线要够亮、手掌离摄像头约 40–70cm，识别最稳。

3 · 鼠标 / 触摸控制

  • 没有摄像头也能玩：直接在画面上按住拖动，鼠标/手指就是引力点。
  • 手机上单指拖动即可，页面已针对移动端做了性能优化。

4 · 面板功能

  • FORM / 形状：Galaxy、Spiral、Flower、Heart、Ring、Singularity、Atom、Infinity、Wave、Sun、DNA、Vortex。
  • Live Morph · 实时形变：开启后形状之间会平滑过渡。
  • MOTION · 运动：速度 / 跟随 / 旋转 / 扰动 / 星尘 五个滑块，实时调节手感。
  • Reset controls：一键恢复默认参数。
  • 底部状态卡显示：摄像头状态、手势 AI 状态、当前形状、FPS、输入方式。

5 · 摄像头打不开怎么办

  • Chrome / Edge 双击打开（file://）会被直接拒绝：不会弹权限框。在本文件所在目录执行 python -m http.server 8765，然后访问 http://localhost:8765/ 打开本文件。
  • 权限被拒绝过：点地址栏左侧摄像头/锁形图标 → 网站设置 → 相机 → 允许，再刷新。
  • 被占用：关掉 Zoom、腾讯会议、微信、OBS、系统相机等软件后重试。
  • 画面全黑 / 输出空帧（状态显示"画面全黑 · 空帧"）：拨开镜头盖或隐私滑板；按键盘上的摄像头 Fn 隐私键；关闭其它占用软件；重新插拔 USB 或换端口；设备管理器 → 摄像头 → 右键 → 更新/重装驱动（可选"USB 视频设备"）；最后重启电脑。
  • Windows 还需：设置 → 隐私和安全性 → 相机 → 打开「允许应用访问相机」。

6 · 手机端

  • 手机浏览器只有在 https 或 localhost 下才能用摄像头；直接访问局域网 IP（192.168.x.x）会被拒绝。
  • 本页已去掉移动端毛玻璃、限制渲染分辨率、降低粒子数；若仍不流畅，会自动进入性能模式（右下角提示）。

画面与摄像头数据全部在本地浏览器内处理，不会上传。
